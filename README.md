# CodeAlpha Task 3: Handwritten Character Recognition

A Convolutional Neural Network (CNN) trained on MNIST handwritten digits. Optional EMNIST letters mode with `--emnist`.

## Setup
```
pip install -r requirements.txt
```

## Run
```
python handwritten_cnn.py
```

MNIST (about 11 MB) downloads automatically on the first run. Results and sample predictions are saved as .png files.
